# OOP-14.1 Homework: Product and Category

## Описание

Проект реализует классы `Product` и `Category` для управления товарами и
категориями, а также функцию загрузки данных из JSON.
Новые возможности (задания 1-5)

### Класс `Product`

- Приватный атрибут `__price` с геттером и сеттером.
- Сеттер проверяет, что цена > 0, иначе выводит сообщение.
- При попытке **понизить** цену требуется подтверждение пользователя (`y`/`n`).
- Класс-метод `new_product` создаёт товар из словаря.

### Класс `Category`

- Приватный список товаров `__products`.
- Метод `add_product` для добавления товара (обновляет `product_count`).
- Свойство `products` возвращает строковое представление всех товаров в формате:
- Название, цена руб. Остаток: количество шт.
- Счётчики `category_count` и `product_count` обновляются автоматически.
